# Issue tracker

This project uses a local Markdown issue tracker.

- Issue and PRD records live under `D:\agent_for_business\.scratch\`.
- Feature folders should use a short kebab-case name.
- Each issue or PRD should include its current triage label in front matter or a clearly visible status field.
- User-facing copies of finalized documents may also be placed under `D:\agent_for_business\outputs\`.
- There is currently no GitHub remote or external issue tracker configured for this project.
